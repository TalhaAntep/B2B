# DealerSystemSetting editability matrix

This matrix covers the 98 source controls (Select2 helper search boxes are excluded). “Editable in the UI” means the control has an editor; persistence is separately indicated below. The absent Web Forms save handler means legacy persistence behavior is unknown for all controls. Normal and Production APIs remain read-only; persistent writes are restricted to explicit authenticated local Development test mode.

- Total inventoried controls: 98
- Previously enabled before the current expansion: 41 controls (38 older adapters plus three typed numeric fields).
- Current reconciled state (2026-11-22): 98 catalog controls are represented and have UI editors. 93 have fixed authenticated Development API persistence adapters and HTTP save/readback/restoration evidence. The five controls with unresolved legacy destinations now use independent application-owned extension persistence; they are editable in the new application, not draft-only, and old-portal compatibility is unverified. Five image controls use separate application-owned file storage and do not update DealerSettings or the legacy portal. Thus all 98 controls have a new-application persistence path (93 settings API adapters plus five asset slots); legacy Web Forms save behavior is verified for zero controls. Original browser DOM evidence confirms `ParameterModules` option `1` and `ParameterAdmin` option `32` as separate controls and columns. Normal API and Production remain read-only; Store5_Analysis is rejected.
